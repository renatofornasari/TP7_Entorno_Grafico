# TP7_Entorno_Grafico
En el presente trabajo práctico consiste en el encendido y apagado de 3 leds de un circuito hecho con Arduino y conectado a la PC mediante el uso de pulsadores y a través de una interfaz gráfica hecha en Processing donde se visualizan las entradas y salidas del circuito como también puede verificarse el estado de conexión entre el Arduino y la PC.
